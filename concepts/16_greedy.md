# Greedy Algorithm

## 한 문장

Greedy는 **매 순간 지금 가장 좋아 보이는 선택을 하는 방법**이다.

단, 중요한 조건이 있다.

> 지금의 최선 선택을 반복해도 전체 최적해가 된다는 근거가 있어야 한다.

## 동전 예제

1260원을 500, 100, 50, 10원 동전으로 최소 개수로 만들자.

```python
money = 1260
coins = [500, 100, 50, 10]
count = 0

for coin in coins:
    count += money // coin
    money %= coin

print(count)  # 6
```

가장 큰 동전을 가능한 만큼 먼저 쓴다.

## 왜 항상 되는 것은 아닌가?

동전이 `[1, 3, 4]`이고 6원을 만든다면 가장 큰 동전부터 고르면:

```text
4 + 1 + 1 = 3개
```

하지만 실제 최적해는:

```text
3 + 3 = 2개
```

따라서 단순히 '큰 것부터'가 아니라 **그 선택이 최적해를 보장하는 문제인지 증명/관찰**해야 한다.

## 회의실 예제

최대한 많은 회의를 배치하려면 종료 시간이 빠른 회의부터 고른다.

```python
def max_meetings(meetings):
    meetings.sort(key=lambda x: x[1])

    count = 0
    end_time = -1

    for start, end in meetings:
        if start >= end_time:
            count += 1
            end_time = end

    return count
```

빨리 끝나는 회의를 고르면 다음 회의를 넣을 남은 시간이 최대가 된다.

## 그리디 사고 순서

1. 지금 선택할 수 있는 후보를 본다.
2. 어떤 기준으로 가장 좋은 후보를 고를지 정한다.
3. 그 선택 때문에 미래의 최적해가 망가지지 않는지 확인한다.
4. 같은 선택을 반복한다.

## 언제 떠올릴까?

- 매 순간 하나씩 선택한다.
- 정렬 후 앞에서부터 고르는 구조가 보인다.
- 최소 동전, 회의 배치, 최소 비용 연결 등에서 지역 최적 선택이 전체 최적을 보장한다.

## 기억법

> Greedy = 지금 가장 좋아 보이는 것을 고른다. 단, 그 욕심이 나중에도 맞는지 근거가 필요하다.
