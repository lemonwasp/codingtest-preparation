# List / Array

## 한 문장

배열/리스트는 **번호가 붙은 사물함을 일렬로 놓은 구조**다.

```text
index:  0   1   2   3
value: 10  20  30  40
```

`arr[2]`라고 하면 컴퓨터는 2번 사물함으로 바로 간다.

## 왜 필요한가?

여러 값을 순서대로 저장하고, 특정 위치의 값을 빠르게 읽기 위해 사용한다.

```python
arr = [10, 20, 30, 40]
print(arr[2])  # 30
```

## 핵심 원리

인덱스를 알고 있으면 바로 접근할 수 있으므로 `arr[i]`는 O(1)이다.

반면 중간에 값을 삽입하면 뒤의 원소들을 밀어야 한다.

```python
arr = [10, 20, 30, 40]
arr.insert(1, 15)
# [10, 15, 20, 30, 40]
```

그래서 중간 삽입/삭제는 O(N)이다.

## Python에서 자주 쓰는 연산

```python
arr = []
arr.append(10)       # 뒤에 추가: 평균 O(1)
arr.append(20)
arr.pop()            # 뒤에서 제거: O(1)
arr[0]               # 인덱스 접근: O(1)
10 in arr            # 값 탐색: O(N)
len(arr)             # 길이: O(1)
```

## 언제 떠올릴까?

- 순서가 중요하다.
- 인덱스로 접근해야 한다.
- DP 테이블을 만들고 싶다.
- 정렬, 이진 탐색, 투 포인터, 누적합의 기반 자료가 필요하다.

## 기억법

> List/Array = 번호가 붙은 사물함. 위치를 알면 바로 찾을 수 있다.
