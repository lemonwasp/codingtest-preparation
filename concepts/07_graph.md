# Graph

## 한 문장

Graph는 **점(Node)과 그 점들을 잇는 선(Edge)으로 관계를 표현하는 구조**다.

```text
A --- B
|     |
C --- D
```

- Node: A, B, C, D
- Edge: A-B, A-C, B-D, C-D

## 왜 필요한가?

도시와 도로, 사람과 친구 관계, 웹페이지와 링크처럼 **누가 누구와 연결되어 있는지** 표현할 때 쓴다.

## 인접 리스트

코딩테스트에서 가장 자주 쓰는 저장 방식이다.

```python
graph = {
    1: [2, 3],
    2: [1, 4],
    3: [1],
    4: [2],
}
```

`graph[1]`은 1번 노드에서 바로 갈 수 있는 노드 목록이다.

숫자 노드가 1~N이면 자주 이렇게 만든다.

```python
graph = [[] for _ in range(n + 1)]

graph[1].append(2)
graph[2].append(1)  # 무방향 그래프라면 반대 방향도 추가
```

## 방향 그래프와 무방향 그래프

```text
1 -> 2   방향 그래프
1 -- 2   무방향 그래프
```

방향 그래프에서는 `1 -> 2`가 있다고 해서 `2 -> 1`도 가능한 것은 아니다.

## 가중치 그래프

길마다 비용이 다르면 가중치를 같이 저장한다.

```python
graph = {
    "A": [("B", 5), ("C", 2)],
    "B": [("D", 1)],
    "C": [("B", 3)],
    "D": [],
}
```

`("B", 5)`는 B까지 가는 비용이 5라는 뜻이다.

## 어떤 알고리즘이 Graph 위에서 움직이나?

- BFS: 가까운 곳부터 탐색
- DFS: 한 길을 끝까지 탐색
- Dijkstra: 양수 가중치 최단거리
- Bellman-Ford: 음수 간선도 가능한 최단거리
- Floyd-Warshall: 모든 쌍 최단거리
- Topological Sort: 선후관계 정렬
- Kruskal: 최소 비용으로 전체 연결

## 기억법

> Graph = 도시와 도로. 알고리즘은 그 도로망을 어떤 규칙으로 돌아다닐지 결정한다.
