## 핵심 관찰

### 1. Two Sum

모든 두 숫자의 조합을 확인하면 O(N²)이 된다. 현재 숫자에 필요한 짝을 계산하고,
이전에 본 숫자들을 Dictionary에서 조회하면 O(N)에 해결할 수 있다.

```python
needed = target - number

if needed in seen:
    return [seen[needed], index]
```

현재 숫자를 저장하기 전에 `needed`를 먼저 확인해야 같은 원소를 두 번 사용하는
오류를 방지할 수 있다.

### 2. Valid Anagram

첫 번째 문자열의 문자 빈도는 증가시키고, 두 번째 문자열의 문자 빈도는 감소시킨다.
최종적으로 모든 빈도가 0이면 두 문자열은 애너그램이다.

```python
return all(count == 0 for count in counts.values())
```

처음 작성한 빈도 계산 알고리즘은 맞았지만, C#·Java 계열 문법과 혼동하여
`!all(counts)`라고 작성했다. Python에서는 `!` 대신 `not`을 사용하며,
Dictionary를 직접 순회하면 값이 아니라 키가 나온다는 점을 배웠다.

## 오늘 익힌 Python 문법

### 1. Dictionary 기본값 조회와 빈도 계산

```python
counts[char] = counts.get(char, 0) + 1
```

`dict.get(key, default)`는 키가 존재하면 기존 값을, 없으면 기본값을 반환한다.
`get()`만 호출해서는 키가 추가되지 않으며, 위 코드에서는 대입 연산이 실제 값을 저장한다.

C#의 다음 코드와 비슷하다.

```csharp
counts[character] = counts.GetValueOrDefault(character, 0) + 1;
```

빈도 계산에서는 다음 패턴을 통째로 기억한다.

```python
frequency[item] = frequency.get(item, 0) + 1
```

### 2. 인덱스와 값을 함께 순회하는 enumerate()

```python
for index, number in enumerate(nums):
    ...
```

`enumerate()`는 0부터 시작하는 인덱스와 현재 값을 함께 제공한다.

```python
nums = [10, 20, 30]

for index, number in enumerate(nums):
    print(index, number)

# 0 10
# 1 20
# 2 30
```

### 3. Dictionary 키 존재 여부 확인

```python
if needed in seen:
    ...
```

Dictionary에 대한 `in`은 키의 존재 여부를 확인하며 평균 시간복잡도는 O(1)이다.

배열에 사용하는 다음 코드는 O(N)이므로 반복문 안에서 사용하면 전체가 O(N²)이 될 수 있다.

```python
if needed in nums:
    ...
```

### 4. Dictionary 순회 방법

```python
for key in counts:
    ...
```

Dictionary를 직접 순회하면 키가 나온다.

값이 필요하면:

```python
for value in counts.values():
    ...
```

키와 값이 모두 필요하면:

```python
for key, value in counts.items():
    ...
```

### 5. Generator expression과 all()

```python
all(count == 0 for count in counts.values())
```

`count == 0 for count in counts.values()`는 각 값에 조건을 적용하는
generator expression이다. `all()`은 모든 결과가 True일 때만 True를 반환하며,
False를 하나 발견하면 즉시 평가를 중단한다.

C# LINQ의 다음 표현과 비슷하다.

```csharp
counts.Values.All(count => count == 0);
```

### 6. any()

```python
any(count < 0 for count in counts.values())
```

`any()`는 하나라도 조건을 만족하면 True를 반환하고 평가를 중단한다.

```text
all() → 전부 참인가?
any() → 하나라도 참인가?
```

### 7. 논리 부정

Python:

```python
not condition
```

C#·Java·JavaScript:

```text
!condition
```

Python에서는 `!condition`을 사용할 수 없다.

### 8. Python 변수명 규칙

Python에서는 지역 변수와 함수 이름에 snake_case를 사용한다.

```python
s_char
t_char
max_profit
```

다음과 같은 camelCase보다 Python다운 표현이다.

```python
sChar
tChar
maxProfit
```
