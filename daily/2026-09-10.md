## Core Idea to Recall

For the kth largest element, keep only the largest `k` values seen so far in a min-heap.

```text
push new value
      ↓
heap size > k ?
  yes → remove smallest
  no  → continue
      ↓
after all values: heap[0] == kth largest
```

The heap does **not** sort every value. It only maintains the current top-`k` group.

## Complexity

For `n` input values and heap size at most `k`:

- each push/pop: `O(log k)`
- total: `O(n log k)`
- extra space: `O(k)`
