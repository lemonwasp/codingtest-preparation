## Key Observations

### Two Sum

Instead of checking every pair, calculate the required complement and look it
up among previously visited numbers.

```python
needed = target - number

if needed in seen:
    return [seen[needed], index]
```

The lookup must happen before inserting the current number. This prevents the
same array element from being used twice.

### Valid Anagram

Add the frequencies from the first string and subtract the frequencies from
the second. The strings are anagrams when all final counts are zero.

```python
return all(count == 0 for count in counts.values())
```

## Python Syntax Learned

### 1. Dictionary default lookup

```python
counts[char] = counts.get(char, 0) + 1
```

`dict.get(key, default)` returns the existing value when the key exists and
the default otherwise. Calling `get()` alone does not insert the key; the
assignment performs the update.

C# equivalent:

```csharp
counts[character] = counts.GetValueOrDefault(character, 0) + 1;
```

### 2. Enumerating index and value

```python
for index, number in enumerate(nums):
    ...
```

`enumerate()` produces both the zero-based index and the current value.

### 3. Dictionary membership

```python
if needed in seen:
    ...
```

Membership checks a dictionary's keys and takes O(1) average time.

### 4. Dictionary iteration

```python
for key in counts:
    ...

for value in counts.values():
    ...
```

Iterating over a dictionary directly returns keys. Use `.values()` when the
stored values are required and `.items()` when both keys and values are
required.

### 5. Generator expressions with all()

```python
all(count == 0 for count in counts.values())
```

The generator evaluates the condition lazily. `all()` returns `True` only
when every generated result is `True), and it stops as soon as it finds a
`False` result.

C# LINQ equivalent:

```csharp
counts.Values.All(count => count == 0);
```

### 6. any()

```python
any(count < 0 for count in counts.values())
```

`any()` returns `True` as soon as one generated result is `True).

### 7. Logical negation

Python uses:

```python
not condition
```

It does not use the C#/Java/JavaScript syntax `!condition`.

### 8. Python naming convention

Use snake_case for local variables:

```python
s_char
t_char
```

rather than camelCase such as `sChar` and `tChar`.
