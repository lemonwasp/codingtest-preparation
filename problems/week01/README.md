# Week 1 — Baseline + Core Implementation

## Objective

Build implementation speed and eliminate avoidable mistakes before moving to heavier algorithms.

Topics:
- arrays / strings
- hash map / set
- sorting
- stack / queue
- simple simulation
- complexity from constraints

## Rules

For every problem:

1. Read constraints before coding.
2. Write the intended complexity.
3. Solve without AI/editorial for up to 25 minutes.
4. Record solve time and result.
5. If hint-dependent or failed, schedule D+1 / D+7 / D+21 re-solves.

## Week 1 Exit Criteria

Move to Week 2 only if most are true:

- [ ] Easy problems are usually solved in <= 20 minutes.
- [ ] Python dictionary/set/deque/sort syntax requires no lookup.
- [ ] I check constraints before choosing an approach.
- [ ] I can state time complexity before submitting.
- [ ] I can explain why each failed attempt failed.
- [ ] The 60-minute mock reaches at least 2/3 solved.

If fewer than four criteria are met, repeat the weakest topic for 2-3 days before starting Week 2.
